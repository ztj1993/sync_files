# sync_url_file.py 测试方案

## 项目概述
为 `sync_url_file.py` 提供完整的单元测试和集成测试，确保文件同步工具的各项功能正常工作。

---

## 测试目标

1. **功能覆盖** - 覆盖所有公共方法和核心逻辑
2. **边界情况** - 处理异常输入和边界条件
3. **模拟依赖** - 使用 Mock 隔离网络请求，确保测试可重复执行
4. **临时文件管理** - 确保测试产生的临时文件及时清理

## 测试技术要点

### 1. Mock 网络请求
使用 `unittest.mock.patch` 模拟 `urlopen`，避免真实网络请求：
```python
@patch.object(sync_url_file, 'urlopen')
def test_download_file(self, mock_urlopen):
    mock_response = MagicMock()
    mock_response.read.side_effect = [b'content', b'']
    mock_urlopen.return_value.__enter__.return_value = mock_response
    # ... 测试代码
```

### 2. 临时文件清理
- **类级别**：`setUp()` 创建临时目录，`tearDown()` 使用 `shutil.rmtree()` 清理
- **方法级别**：使用 `self.addCleanup(os.unlink, config_path)` 确保临时配置文件被删除

### 3. 日志控制
测试开始时禁用日志输出，避免干扰：
```python
logging.disable(logging.CRITICAL)
```

### 4. 模块导入
由于测试文件位于 `tests/` 目录，需要动态导入父目录的模块：
```python
sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
import importlib.util
spec = importlib.util.spec_from_file_location("sync_url_file", ...)
```
